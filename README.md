<a id="overview"></a>

With its timeline-based vector and bitmap animation capabilities, the **latest version** provides a complete software package that ensures you have all features available to enhance your creative projects. Designed for both beginners and professionals, Adobe Animate CC enables the creation of interactive animations that can be published to HTML5 Canvas, Adobe AIR, sprite sheets, animated GIFs, and more.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Timeline-Based Animation** — Create detailed animations using a layered timeline and keyframed motion.
- **Interactivity Scripting** — Utilize JavaScript for HTML5 Canvas and ActionScript 3 for Adobe AIR projects to add engaging interactivity.
- **Asset Warp Tool** — Generate mesh deformations over vector or bitmap artwork for flexible animations.
- **Onion Skinning** — Visualize frames and create smooth transitions between keyframes.
- **Multi-Format Publishing** — Output your projects in various formats including HTML/JS, AIR packages, sprite sheets, and animated GIFs.

### Advanced Features:
- **Envelope Deformer** — Reshape edges with Bezier handles for detailed geometric control.
- **Flexi Bones** — Add bendable segments for articulated rigs and complex animations.
- **Quick Share Panel** — Easily export your creations without diving into complex settings.
